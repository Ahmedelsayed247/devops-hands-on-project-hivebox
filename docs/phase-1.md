# HiveBox - Phase 1

## Project Overview

HiveBox is a hands-on DevOps project
that processes environmental sensor data.

## Project Management

We use Kanban to organize and track tasks.

GitHub Projects is used for project management.

## Repository Strategy

- Fork the official repository.
- Work using separate branches.
- Use Pull Requests.
- Avoid direct commits to main.

## Data Source

We use openSenseMap as our
environmental sensor data source.

## Selected Sensors

Three nearby senseBoxes were selected.

See sensors.md for their IDs.

## Phase 1 Goals

- Set up project management.
- Prepare the GitHub repository.
- Select three senseBoxes.
- Document project decisions.
